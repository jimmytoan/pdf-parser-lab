# D8: which PDF parser should feed a RAG pipeline?

A reproducible lab that compares open-source PDF parsers on two things: how well they parse
(stage 1) and whether a RAG chatbot built on their output answers correctly (stage 2).

Rules this lab keeps:
- **Open source only.** Every parser, the embedding model (BAAI/bge-m3) and the answering model
  (Qwen3-4B-Instruct-2507, 4-bit MLX) run locally on the laptop. No hosted API is called; the
  harness refuses any contestant marked hosted and the spend cap defaults to $0.
- **Synthetic documents only.** The corpus is generated by `lab/corpus.py` from a seeded
  fictional world (Corvane Maritime Group). No customer, company or personal data.
- **Scripted grading.** Ground truth is known by construction; answers are graded by normalised
  match, never by a model judge.

## Layout

| Path | What |
|---|---|
| `RESEARCH.md` | Published comparisons, where they disagree, gaps, and this lab's design |
| `PLAN.md` | Options S, M, L for the full run, with numbers from the pilot |
| `CONTESTANTS.md` | Versions, licences (AGPL / non-commercial flagged), dropped tools |
| `lab/corpus.py`, `lab/layout.py` | Corpus generator (PDFs, per-page truth, questions) |
| `lab/adapters/` | One adapter per parser; each runs in its own venv and writes `pages.json` |
| `lab/contestants.py` | Registry: venv, adapter, licence, `hosted` flag |
| `lab/score.py` | Stage 1 metrics: text similarity, reading order, TEDS, form fields, silent empties |
| `lab/rag.py` | Stage 2: two chunkers, embedder, retrieval, answerer, grader |
| `lab/run.py` | Harness: `sets`, `parse`, `score`, `rag`, `report`, `self-test` |
| `corpus/` | Generated PDFs, truth JSON, `questions.jsonl`, `manifest.json`, pilot PDFs |
| `results/runs.jsonl` | One record per parse job and per RAG question, tagged |
| `results/<tag>/report.md` | Report for a tag |

## Reproduce

```bash
scripts/install_envs.sh                     # one venv per heavy parser under envs/
.venv/bin/python scripts/download_models.py # or envs/mlx/bin/python
.venv/bin/python lab/corpus.py              # regenerate corpus (seeded, deterministic)
.venv/bin/python lab/run.py sets            # pilot PDFs
.venv/bin/python lab/run.py self-test       # no parsers, no models
.venv/bin/python lab/run.py parse --set pilot --tag pilot --resume
.venv/bin/python lab/run.py rag   --set pilot --tag pilot --resume
.venv/bin/python lab/run.py report --set pilot --tag pilot
```

Fonts used in the generated PDFs are open (DejaVu, Noto Sans SC, Kalam, Caveat; OFL or
Bitstream Vera licences). Tesseract language data is `tessdata_fast` (Apache-2.0).
